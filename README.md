# RIFTWATCH for Android

Download the latest Android APK from [Releases](https://github.com/Ellesonntseare/RIFTWATCH-APK-Releases/releases/latest), or use the [direct APK link](https://github.com/Ellesonntseare/RIFTWATCH-APK-Releases/releases/latest/download/RIFTWATCH.apk).

This repository contains **APK releases only**. The game source and build workflow are in [RIFTWATCH](https://github.com/Ellesonntseare/RIFTWATCH).

## Install

1. Download `RIFTWATCH.apk` on your Android phone.
2. Open the downloaded file and allow installation from your browser or file manager if Android asks.
3. Open RIFTWATCH. Room multiplayer and voice require an internet connection to a running RIFTWATCH server.

This is a development build. Each release states the source commit and build run used to produce its APK.
